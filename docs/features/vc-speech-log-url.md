`#vc-speech-log` へのメッセージリンクが投稿された際、リンク先メッセージの内容を引用して投稿します。

## 引用対象のチャンネル

引用の対象となるチャンネルは、Admin が [`/jaotants vc-speech-log`](../commands/jaotants.md) コマンドで追加・削除・確認できます。変更はすぐに反映されます。
